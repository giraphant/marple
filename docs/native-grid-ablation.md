# 原生规则网格与消融对照

2026-09-20。范围是四栏中的浏览区；阅读器、属性区和窗口结构保持原样。

## 参考与实现

参考 [OpenEmu 的原生 Flow Layout](https://github.com/OpenEmu/OpenEmu/blob/1d205104640d8410659d321809889cbfd06b99a9/OpenEmu/ImageCollectionViewController.swift)，沿用 Marple 的 `NSCollectionView`，用 `NSCollectionViewFlowLayout` 负责规则行列与键盘几何。小型子类只控制缩略图尺寸及居中边距。没有增加第三方依赖或额外网格模式。

卡片采用固定预览区、两行标题和一行元信息。文字预览最多三行，图片完整缩放到预览区；评分、标签及来源的独立行从卡片上移除，仍可在现有阅读器/属性区查看。评分和摘要长度不再决定高度，删除瀑布流高度缓存及方向键全量邻居搜索。

密度滑块直接改变单元尺寸，即使仍是一列也有连续可见的变化。缩略图重新解码仅在像素尺寸档位改变时触发。保留既有 Space 拖拽协议与手动拖拽路径；新条目的选择在按下时响应，拖动已选条目仍携带整组选择。

## 消融方法

同一组 600 条合成资料，包含论文、图书、笔记、讲座、图片以及长短不一的摘要。用真实 AppKit 窗口在 320、420、540 pt 栏宽下截图，未读取或修改生产资料库。

1. **现状**：旧瀑布流、旧卡片，目标宽度设为旧滑块下限 180 pt。
2. **只换布局**：规则行列，保留旧字体、内容和实际列宽。统一行高取该批旧卡片的最大高度，确保旧内容能放下。
3. **完整简化**：规则行列及固定内容槽。另保留 248 pt 单元的 540 pt 栏宽截图，以对照前两组的相同实际列宽；默认紧凑尺寸单独展示。

前两组截图可直接看出：规则排列解决了定位的可预测性，但仅把旧卡片等高会制造大片空白。需要同时收敛卡片信息，才能使用较小而稳定的单元。

| 栏宽 | 旧瀑布流可见条目 | 仅规则排列可见条目 | 最终默认 136 pt 卡片 |
| --- | ---: | ---: | ---: |
| 320 pt | 4 | 3 | 10 |
| 420 pt | 9 | 6 | 10 |
| 540 pt | 9 | 6 | 15 |

可见数量包含局部露出的末行，来自 `indexPathsForVisibleItems()`；这一比较用于说明布局密度，不代表任务完成速度。最终默认值使用更小的卡片，不能把数量变化全部归因于布局算法。540 pt 栏宽、相同 248 pt 单元下，最终版与仅规则排列均显示 6 条；主要差别是内容收敛与规则对齐。

临时消融程序位于本地 `.orca/experiments/2026-09-20-native-grid/GridAblationTests.swift`，以 `af0137a` 的旧卡片/布局为基线。它打印的 `prepare` 耗时没有复现旧版完整高度缓存，因此不作为新旧性能提升的证据。

## 单元复用的根因修复

最初尝试 `register` + `makeItem` 复用时，复现了旧代码绕开的 nib 加载异常。独立小程序确认根因是初始化顺序：设置第一个现代布局会替换 AppKit 内部的旧式 core，布局之前的单元注册随之丢失。把注册放在设置布局之后，即可正常创建代码实现的单元，无须创建 nib、引入自有复用池或改变打包方式。

独立复现程序保存在本地 `.orca/experiments/2026-09-20-native-grid/collection-reuse.swift`。`layout-first` 成功，`register-first` 复现未注册单元异常；正式代码采用前者。

## 验证范围

`LibraryGridTests` 覆盖窄栏规则排列、同一列数下的连续缩放、选择保持、原生方向键、Command 多选、Space 拖拽载荷、同路径标题更新、外部打开条目同步以及图片/文字单元复用。`LibraryTableTests` 继续验证三种浏览方式切换时四栏及右侧控制器保持不变。

布局测试还复现了同时改变栏宽与卡片尺寸时，Flow Layout 第一轮沿用旧边距的问题。尺寸计算移到 collection view 的 `setFrameSize` 调用父类之前后，三个栏宽与五个卡片尺寸的组合全部通过。

全量 `swift test --package-path apple -c release` 报告 1,040 项通过；原有需要外部环境的性能基准及 tokenizer 对照测试按条件跳过。浅色、深色、图片完整缩放、单元复用以及四栏整体均生成了截图。消融截图及日志保存在本地 `.orca/experiments/2026-09-20-native-grid/`。

本机使用 Command Line Tools / macOS SDK 15.5，测试时有临时编译兼容垫片，垫片不进入提交。没有用旧 SDK 安装或发布应用；现代 macOS 工具栏外观应由正式 Xcode 工具链验证。拖拽载荷和图像在测试中检查，真实跨窗口鼠标拖放不等同于这些自动化检查。
