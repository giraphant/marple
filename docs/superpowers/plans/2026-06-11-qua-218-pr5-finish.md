# QUA-218 PR5 — 收尾：清警告 + AppModel 拆 extension + Integrations 归位

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** QUA-218 终期收尾——清掉基线警告（干净构建）、把 1822 行 AppModel 按关注点拆成 extension 文件（可读性"瘦身"，行为零变化）、把 CLI/BackupScheduler 归入 `Marple/Integrations/`、删真死的 catalog 转发。

**Architecture:** 沿用 PR3a 给 Catalog 拆 extension 的同款手法：`AppModel.swift` 保留 `@Observable` 类声明 + 全部存储属性 + init/DI + catalog 转发（@Observable 宏要求存储属性留主类），方法按关注点逐字搬进 `AppModel+X.swift`。警告清理是点状小改。Integrations 是机械 git mv（同模块 Marple，无层级变更）。**不做**：视图直读 catalog 删全部转发（转发是正确的组合根契约，删=8 视图文件 churn 低 ROI）；MarpleKit Superset 基础设施跨模块搬到壳（层级风险 > 价值）。

**Tech Stack:** Swift 6 / SwiftPM / swift-testing。`apple/.build` 符号链接**永不删**。`@Observable` 宏：存储属性必须留主类，extension 只放方法。基线警告（本期清零）：CollectionGridVariant MainActor ×2、VectorStore cblas_sgemv ×1、Fixtures unhandled ×1。`swift test` 收尾可能 SIGPIPE exit 13（QUA-208）。

## 计划级决策（已定）

1. **AppModel 拆 extension = 文件级瘦身**：类仍大（导航/工作区状态机交织、不可抽），但 `AppModel.swift` 巨文件拆成聚焦文件。方法体逐字搬（cut/paste），存储属性 + init + 转发留主类（@Observable 约束）。行为零变化。
2. **保留 16 转发**：研究确认转发是组合根契约，视图读 `model.X` 不变。**例外**：逐一核实后删真死的转发（无 view 且无 AppModel 内部读者的）——`topicMembership`/`relationGraph` 疑似死（recomputeOpenDerived 已搬 Catalog、用自身的）；`searchIndex` 被 `commandSearch` 内部读，**不删**。每个删除前 `grep model.<name>` + AppModel 内部 `self.<name>`/`<name>` 双核。
3. **Integrations 仅搬同模块壳文件**：`Marple/CLI/*`（3 文件）+ `Marple/Backup/BackupScheduler.swift` → `Marple/Integrations/`。`BackupBrowserView.swift`（SwiftUI 视图）一并搬到 `Integrations/Backup/`（它是 Backup 功能的 UI，归拢合理）。MarpleKit 的 Superset/Backup 基础设施**不动**（它们是核心、平台无关或已 macOS-guard）。
4. **警告清理逐项最小改**：CollectionGridVariant 给 `beginPreviewPanelControl` override 标 `@MainActor`（QLPreviewPanel dataSource/delegate 是 @MainActor 属性）；VectorStore 加 `-DACCELERATE_NEW_LAPACK`/`-DACCELERATE_LAPACK_ILP64` swiftSettings（同 cblas_sgemv 调用，Int32 LP64-safe）；Fixtures 在 Package.swift 的 MarpleKitTests 加 `resources: [.process("Fixtures/qwen3-embedding-0.6B-oracle.json")]`；DateFormatter 把 SupersetLog 每行 alloc 改 static 缓存 + 收拢两处 zh_CN `"yyyy-MM-dd HH:mm"` 到一个共享 helper。
5. **行为零变化**：拆分逐字、警告修等价（CBLAS 同调用、@MainActor 不改运行时行为因本就主线程调用、Fixtures 是构建声明、DateFormatter 缓存不改输出）。测试 + 构建作钉。
